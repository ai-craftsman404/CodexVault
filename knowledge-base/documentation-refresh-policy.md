# Documentation Refresh Policy

## Purpose

Codex plugin capabilities, publishing workflows, MCP support, app connector behavior, and skill guidance can change. This factory treats documentation freshness as part of plugin quality.

## Cadence

- Default: every four weeks.
- Active release work: bi-weekly.
- Final release: refresh before packaging if the last check is more than two weeks old.

## Sources

- OpenAI Codex plugin docs: https://developers.openai.com/codex/plugins
- OpenAI build plugins guide: https://developers.openai.com/codex/plugins/build
- OpenAI Codex skills docs: https://developers.openai.com/codex/skills
- OpenAI Codex security and approvals docs: https://developers.openai.com/codex/agent-approvals-security
- Agent Skills standard: https://agentskills.io/
- OpenAI Codex GitHub repository: https://github.com/openai/codex

## Required Output

Record each review in `registry/research-log.md` with:

- date checked
- sources checked
- notable changes
- impact on the factory process
- recommended updates
- next recheck trigger
