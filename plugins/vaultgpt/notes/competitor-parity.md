# VaultGPT Competitor Parity Notes

## Competitors Discussed

- Superpower ChatGPT
- ChatGPT Toolbox / AI Toolbox

## Market-Validated Feature Categories

- Folders and subfolders
- Pins and favorites
- Full-text chat search
- Export to Markdown, JSON, TXT, PDF, or HTML
- Bulk export
- Bulk delete or archive
- Prompt library
- Prompt variables
- Prompt chaining
- Tags and labels
- Notes and bookmarks
- Media or attachment awareness
- Activity and export logs

## Competitor Strengths

Superpower ChatGPT appears strong in broad ChatGPT UI utilities, prompt management, notes, pinned messages, exports, and automation such as archive/delete helpers.

ChatGPT Toolbox / AI Toolbox appears strong in folder organization, full-text search, bulk actions, labels, prompt chaining, local browser storage claims, and visible paid pricing.

## VaultGPT Parity Goal

VaultGPT should cover the high-value popular workflows users already understand from third-party ChatGPT extensions, especially workflows that are capped or paid:

- organize conversations
- search conversations
- export conversations
- bulk process conversations
- preserve prompts
- extract knowledge
- operate safely on private archives

## Competitive Wedge

VaultGPT should not win by adding more UI complexity. It should win by offering familiar extension-style power features through a free, local-first, Codex-native, auditable workflow.

## Paid-Feature Targets

The highest-priority parity targets are features commonly limited or monetized by competitors:

- unlimited folders and subfolders
- unlimited pins or favorites
- unlimited saved prompts
- full-text search without low result caps
- bulk export
- bulk delete or archive with safety gates
- prompt chaining
- labels or smart tags
- cross-device sync equivalent through a portable local vault
- team/admin governance later through audit logs and policy controls

## Trust-Replacement Targets

VaultGPT should explicitly replace the risky parts of the extension model:

- avoid always-on high-privilege extension behavior where possible
- keep captured data local by default
- make browser actions visible and user-approved
- preserve audit logs for capture, export, redaction, and delete/archive actions
- use privacy review before saving, indexing, or exporting sensitive material
- provide clear provenance from output back to source chats
